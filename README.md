<h1 align="center">Compose Desktop Media Player</h1>

This repository contains examples of implementing a media (audio/video) player for Jetpack Compose Desktop using various
libraries

> [!NOTE]
> The application was designed using the [Reduce & Conquer](https://github.com/numq/reduce-and-conquer) architectural
> pattern

## [Klarity](https://github.com/numq/Klarity)

This is an FFmpeg-based library that I created to integrate a media player directly into Composable using Skia, avoiding
compatibility and interoperability issues

## [VLCJ](https://github.com/caprica/vlcj)

JVM bindings for VLC

## [JavaFX MediaPlayer](https://docs.oracle.com/javafx/2/api/javafx/scene/media/MediaPlayer.html)

Official library for the JavaFX framework
